# pSite-opt and CredAlign

This repository contains two tools:

- **pSite-opt**: unified amino acid (AA) confidence evaluation for peptide-spectrum matches (PSMs) from *de novo* peptide sequencing.
- **CredAlign**: AA confidence-weighted adaptive local alignment for source tracing of error-prone *de novo* sequenced peptides.

# Overview

*De novo* peptide sequencing is a key technology for discovering the dark matter of the proteome, but its output sequences often contain erroneous AA sites that severely interfere with downstream biological source tracing. Existing sequence alignment-based source-tracing strategies assume equal reliability for all AA sites in their core scoring logic, without considering site-specific confidence differences, allowing low-confidence erroneous sites to mislead the optimal alignment path through fortuitous matches. AA confidence thus represents an underutilized key factor for improving the source-tracing accuracy of *de novo* sequenced peptides. To address this, we optimized the pSite algorithm to obtain pSite-opt, enabling unified AA confidence scoring for PSMs generated by different *de novo* sequencing tools, and we implemented CredAlign based on the Smith-Waterman dynamic programming framework, which embeds AA confidence into the match scoring function to achieve quality-aware adaptive local alignment. Across nine testing scenarios, CredAlign with confidence weighting significantly improved amino acid recall compared with the unweighted mode, and the magnitude of improvement was positively correlated with the proportion of erroneous sites in the query sequences. In practical applications, CredAlign corrected misalignments caused by low-confidence segments and identified novel peptides encoded by the human *RNF40*, *SPAG1*, and *RAI1* genes. This study demonstrates that integrating AA confidence into the core scoring logic of sequence alignment can effectively improve the source-tracing accuracy of error-prone *de novo* sequenced peptides. This confidence-weighting strategy is independent of specific alignment algorithms and can serve as a reference for other source-tracing tools.

# Usage

## pSite-opt

pSite-opt assigns AA confidence scores to *de novo* sequenced peptides. It provides unified AA confidence evaluation for PSMs generated by different *de novo* sequencing tools and can be used as the confidence input for CredAlign.

### Input Preparation

Place the input files in:

```text
./Release/net6.0/Input
```

Required input:

- **DenovoPSM.csv**: No header row. Each line contains a spectrum name and a *de novo* sequenced peptide, separated by a comma.
  Format: `<spectrum_name>,<de_novo_peptide>`
  Example: `151009_exo3_1.4506.4506.4.1.dta,AQQSSALLAQAMLPMR`

- **One or more MGF spectrum files** (`*.mgf`): The spectrum name in `DenovoPSM.csv` and the spectrum title/identifier in the MGF file are matched by partial overlap; they do not have to be exactly the same.

### Run pSite-opt

Double-click `pSite-opt.exe` in `./Release/net6.0/`, or run from the command line:

```cmd
cd ./Release/net6.0/
pSite-opt.exe
```

### Output Interpretation

Results are written to:

```text
./Release/net6.0/Output
```

The output is a `.csv` file. Each line contains:

`<spectrum_name>,<de_novo_peptide>,<score_1> <score_2> ... <score_L>`

where `L` is the length of the *de novo* sequenced peptide. The confidence scores are separated by spaces and correspond one-to-one to the AAs in the peptide, from the N-terminus to the C-terminus.

Example:

```text
151009_exo3_1.4506.4506.4.1.dta,AQQSSALLAQAMLPMR,37.53886 8.66408 6.32757 4.0702 3.0395 5.52955 60.61168 75.59622 57.96632 74.87783 35.1827 0.08527 1.87005 0.60685 0.05041 34.47635
```

In this example, the peptide `AQQSSALLAQAMLPMR` has 16 AAs, and 16 confidence scores are reported.

## CredAlign

### Input Preparation

Prepare the following input files and directories:

- **BLOSUM62 matrix**: Place standard BLOSUM62 scoring matrix files in `./Release/net6.0/BLOSUM62/`

- **Query sequences**:
  - Place one or more `.csv` files in `./Release/net6.0/Query/`
  - Each line in the CSV file represents one query sequence, formatted as:
    `Amino_acid_sequence,Amino_acid_confidence_scores`
  - Example: `LHFLTEPAEVNPGR,98.7612 97.42165 99.97832 99.83066 99.02905 99.61818 98.94964 37.70059 68.17488 22.33408 54.68313 61.94963 4.88969 96.74363`

- **Template sequences**:
  - Place one or more `.csv` files in `./Release/net6.0/Template/`
  - Each line in the CSV file represents one template sequence

*Note: The program will perform pairwise local sequence alignment: **every query sequence against every template sequence automatically***.

### Run CredAlign

Execute the program by double-clicking `CredAlign.exe` in `./Release/net6.0/`  
After completion, all alignment results will be generated in `./Release/net6.0/Result/`

### Output Interpretation

Each line represents a CredAlign alignment result with the following semicolon-separated format:

`Query:Query_sequence,Confidence_scores;Template:Template_sequence;CredAlign_Result:Aligned_query,Aligned_template,CIGAR_string`

Example of a complete result line:

`Query:LHFLTEPAEVNPGR,98.7612 97.42165 99.97832 99.83066 99.02905 99.61818 98.94964 37.70059 68.17488 22.33408 54.68313 61.94963 4.88969 96.74363;
Template:PPRPPRP.PRQLLPVMQTLTSRIHFLTEPAEPAGAARAAQPCVMGNIQKKLTGKAEGGK;CredAlign_Result:
LHFLTEPAE.VNPGR(query),IHFLTEPAEPAGAAR(template),MMMMMMMMMDMMMMM(CIGAR)`

The specific meanings of each field are:

- **Query**: Input query sequence and its corresponding AA confidence scores
- **Template**: Input template sequence used for alignment
- **CredAlign_Result**:
  - Aligned query sequence (marked with `query`)
  - Aligned template sequence (marked with `template`)
  - Standard CIGAR string for alignment annotation (marked with `CIGAR`)
